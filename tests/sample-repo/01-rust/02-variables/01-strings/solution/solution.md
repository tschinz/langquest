---
title    = "String Concatenation"
hints    = [
    "Use `format!()` to combine two values into a string",
    "Add a space between the two parameters",
]
keywords = []
---

Use `format!(\"{} {}\", a, b)` to concatenate the two strings with a space between them. The `format!` macro works like `println!` but returns a `String` instead of printing.
