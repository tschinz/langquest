# String Concatenation

Implement the `concat` function so it takes two string slices and returns a single `String` that concatenates them with a space in between.

## Expected Results

- `concat("Hello", "World")` → `"Hello World"`
- `concat("foo", "bar")` → `"foo bar"`
- `concat("", "test")` → `" test"`
