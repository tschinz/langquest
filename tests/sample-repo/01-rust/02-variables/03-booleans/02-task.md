# Boolean Logic

Implement the following functions:

1. `is_even(n)` — returns `true` if `n` is even
2. `is_positive(n)` — returns `true` if `n` is greater than zero
3. `both_even(a, b)` — returns `true` if both `a` and `b` are even

## Expected Results

- `is_even(4)` → `true`
- `is_even(7)` → `false`
- `is_positive(-3)` → `false`
- `is_positive(5)` → `true`
- `both_even(2, 8)` → `true`
- `both_even(3, 6)` → `false`
