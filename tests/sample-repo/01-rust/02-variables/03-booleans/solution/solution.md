    "Use the `%` (remainder) operator to check if a number is even",
    "Use `>` to check if a number is positive",
    "Combine two conditions with `&&` for both_even",
]
keywords = []
---

- `is_even`: `n % 2 == 0` — if the remainder of division by 2 is 0, the number is even.
- `is_positive`: `n > 0`
- `both_even`: `a % 2 == 0 && b % 2 == 0` — use `&&` to combine both checks.
