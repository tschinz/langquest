# Basic Arithmetic

Implement the following arithmetic functions:

1. `add(a, b)` — returns `a + b`
2. `multiply(a, b)` — returns `a * b`
3. `average(a, b)` — returns the average of `a` and `b` as an `f64`

## Expected Results

- `add(3, 4)` → `7`
- `multiply(5, 6)` → `30`
- `average(10, 20)` → `15.0`
